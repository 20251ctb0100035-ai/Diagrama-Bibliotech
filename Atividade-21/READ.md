# 2026-APS-DoceAgenda

Sistema de gestão de encomendas e clientes para pequena confeitaria artesanal.

* **Autor:** Anthony Pagani
* **Cliente:** Mariana (Confeiteira)
* **Disciplina:** Análise e Projeto de Sistemas (2026) - IFPR Centro de Referência Ponta Grossa

---

## Apresentação do Projeto

O DoceAgenda é um sistema desenvolvido para organizar o recebimento de pedidos de uma confeitaria artesanal, substituindo anotações informais em cadernos e conversas dispersas do WhatsApp. Ele permite registrar clientes, cadastrar os produtos do cardápio, agendar entregas e controlar o status de cada encomenda. Com isso, evita-se o esquecimento de prazos de entrega e o erro na separação dos pedidos dos clientes.
