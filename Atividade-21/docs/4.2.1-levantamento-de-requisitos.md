# 4.2.1 Levantamento de Requisitos

## Técnicas de Levantamento Utilizadas

- **Entrevista Semiestruturada:** Conversa direta com a cliente Mariana para entender a rotina de recebimento de pedidos no WhatsApp.
- **Análise de Artefatos:** Leitura e análise das fotos do caderno de anotações e mensagens trocadas com clientes.

## Da fala à necessidade

| Fala do Cliente | Necessidade Identificada |
| --- | --- |
| "Às vezes me perco nas datas e quase esqueço de entregar." | Registrar data e hora limite com alerta visual na agenda diária. |
| "O cliente pede um bolo recheado e depois diz que pediu de outro sabor." | Registrar os detalhes/itens da encomenda vinculados ao cliente de forma imutável. |
| "Quero um botão verde pra aprovar o pedido no WhatsApp." | *(Reescrito)* O sistema deve permitir o registro direto de pedidos confirmados pela confeiteira. |

## Histórias de Usuário

- **US01:** Como confeiteira, quero cadastrar meus clientes com nome e WhatsApp, para que eu possa identificar quem fez cada pedido.
- **US02:** Como confeiteira, quero cadastrar produtos no cardápio, para agilizar a montagem das encomendas.
- **US03:** Como confeiteira, quero registrar uma encomenda informando data/hora de entrega, para não perder prazos.
- **US04:** Como confeiteira, quero visualizar a agenda do dia e da semana, para organizar minha produção diária.

## Requisitos Funcionais (RF)

| Código | Nome (Verbo + Objeto) | Descrição | Veio de (Origem) |
| --- | --- | --- | --- |
| **RF01** | Cadastrar Cliente | O sistema deve permitir cadastrar e atualizar dados do cliente (Nome, Telefone/WhatsApp). | US01 |
| **RF02** | Cadastrar Produto | O sistema deve permitir cadastrar produtos do cardápio com nome, descrição e preço base. | US02 |
| **RF03** | Registrar Encomenda | O sistema deve registrar uma nova encomenda com cliente, itens, data e hora de entrega. | US03 |
| **RF04** | Listar Agenda | O sistema deve exibir as encomendas agrupadas por dia e por semana. | US04 |
| **RF05** | Atualizar Status da Encomenda | O sistema deve permitir alterar o status da encomenda (Pendente, Em Produção, Entregue, Cancelado). | Fala da cliente |

## Requisitos Não Funcionais (RNF)

| Código | Categoria | Descrição |
| --- | --- | --- |
| **RNF01** | Desempenho | A tela de agenda diária deve carregar em menos de 3 segundos. |
| **RNF02** | Usabilidade | O sistema deve possuir interface responsiva adaptada a telas de smartphones. |
| **RNF03** | Segurança | O acesso ao sistema é restrito mediante autenticação de usuário e senha. |

## Conferência com a 4.1

- **O que a conferência mudou:** A funcionalidade de "Cancelar Encomenda" foi adicionada ao escopo do RF05 após percebermos na 4.1 que pedidos podiam ser desistidos antes da produção.
- **❓ Dúvidas em aberto:** ❓ Caso a cliente mude de número, histórico de pedidos antigos deve ser mantido? *Adotado provisoriamente que o cadastro do cliente apenas atualiza o número mantendo as encomendas vinculadas.*
